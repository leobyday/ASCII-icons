# Installing on iPhone

iOS doesn't let apps or scripts replace another app's icon, so the icons go on through the Shortcuts app. It takes about a minute per app.

## 1. Get the images onto your phone

Send `icons/ios/` and `icons/wallpapers/ios.png` to your phone (AirDrop, iCloud Drive or Files), then save them to Photos.

## 2. Add an icon for each app

1. Open **Shortcuts** and tap **+**.
2. **Add Action** → search **Open App** → pick the app.
3. Tap the shortcut's name at the top → **Add to Home Screen**.
4. Tap the small icon → **Choose Photo** → pick that app's PNG.
5. Name it after the app and tap **Add**.

## 3. Hide the originals

Long-press each original icon → **Remove App** → **Remove from Home Screen**. The app stays installed in the App Library.

## 4. Finish the look

- **Wallpaper:** Photos → `ios.png` → Share → **Use as Wallpaper**.
- **Light mode:** Settings → Display & Brightness → Light.
- **Everything else in grayscale:** home screen → long-press → **Edit** → **Customize** → **Tinted**, with a gray tint.

## Things to know

- Shortcut icons don't show notification badges.
- Icons are still images; iOS doesn't animate icons.
- Folders can go in the dock, but iOS draws the folder itself.
- Settings and the inside of apps keep Apple's look.
